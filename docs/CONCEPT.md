# Brilliantis concept

Brilliantis is an open-source CRM and ERP released under the MIT License. It brings
business partners, contacts, leads, deals, quotes, contracts, invoices and payments
into one shared workspace.

People work through the embedded web interface. Agents use the REST/OpenAPI
interface with scoped access, idempotent commands and an audit trail. Brilliantis
does not require a particular AI provider.

A single Rust binary includes the web UI and uses SQLite for storage. It can run
locally, on a small server or on Kubernetes. The project is an early-stage open-source
release; APIs and data models may change. The demo uses fictitious data.

## Kurzfassung

Brilliantis ist ein quelloffenes CRM und ERP unter der MIT-Lizenz. Geschäftspartner,
Vertrieb, Angebote, Verträge, Rechnungen und Zahlungen teilen sich einen Arbeitsbereich.
Menschen nutzen die eingebettete Oberfläche, Agenten die REST/OpenAPI-Schnittstelle
mit begrenzten Zugriffsrechten und nachvollziehbaren Aktionen. Ein einzelnes
Rust-Binary mit SQLite ermöglicht den lokalen Betrieb oder die Bereitstellung auf
einem Server. Das Projekt befindet sich in einer frühen Entwicklungsphase.
